## Reflection

Working in healthcare has made protecting the end user personal to me. I regularly speak with Medicare members who worry about scams and whether they can trust the systems they are being asked to use. This course helped me connect those concerns to decisions developers make about input validation, permissions, error handling, and testing.

For Project Two, I expanded my GoogleTest milestone with additional vector boundary tests. All 17 tests passed. That was encouraging, but it also helped me recognize that passing tests only demonstrate the behavior those tests actually cover.

I am leaving this course with more questions to ask before considering code finished. What could someone access that they should not? What happens when an operation fails? Who is affected if the protection does not work? Those are questions I want to carry into my future development
